# FK Planner

Личная мастерская для подготовки к Фандомной битве (ФБ / FK).

## Запуск

В IntelliJ IDEA открой вкладку Terminal в корне проекта и выполни:

```sh
npm install
npm run dev
```

Открой адрес, который покажет Vite (обычно `http://localhost:5173`).

## Хранение данных

Без настроек Supabase сезоны, левелы, карточки и прогресс хранятся локально в браузере. Изображения сохраняются в IndexedDB.

Для аккаунта и синхронизации между устройствами создай `.env.local` по примеру `.env.example`, укажи URL проекта Supabase и publishable key, затем выполни SQL-настройку из `supabase/`. После перезапуска приложения будут доступны регистрация, вход, облачное хранение данных и изображений.

Сохранённые данные содержат версию схемы. Чтение проверяет их структуру и поддерживает прежний формат без версии. Если локальные данные повреждены, исходное содержимое дополнительно сохраняется в `fk-planner-v1-invalid-backup` в localStorage.

## Возможности

- сезоны ФБ, левелы и шаблоны зимнего и летнего сезонов;
- карточки текстов, артов и крафта с маршрутами этапов;
- учёт написанных слов и дневной ориентир до софт-дедлайна;
- доска по левелам, перенос карточек и диаграмма Ганта;
- заметки и изображения в карточках;
- аккаунт и синхронизация с Supabase при настройке окружения.

## Проверки

Для встроенных unit-тестов нужен Node.js 24 или новее.

```sh
npm run build
npm run lint
npm run test:unit
```
